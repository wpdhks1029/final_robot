# 2026-11-01 최신 재시작 순서

선두/후발 노드가 모두 종료된 새 세션 기준. 이미 실행 중인 항목은 중복 실행하지 않는다.
선두 기존 IP10.253.245.81, 후발10.253.245.192 기준이다.

각 SSH 터미널에서 접속한 뒤 공통 설정:

```bash
source /opt/ros/humble/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=10
export ROS_LOCALHOST_ONLY=0
```

## 터미널별 실행

1. 선두 ubuntu: 센서/TF/EKF/모터 제어기
```bash
ros2 launch ~/leader_diagnostics/leader_nav_015_base.launch.py allow_motion:=true
```

2. 선두 ubuntu: 지도/AMCL
```bash
ros2 launch nav2_bringup localization_launch.py map:=/home/sunuk/robot_ws/maps/leader_map.yaml params_file:=/home/sunuk/leader_diagnostics/nav2_015_rotation_shim_check.yaml use_sim_time:=false autostart:=true
```

3. 선두 ubuntu: bridge (초기 위치 지정 전 TF 경고가 나올 수 있음)
```bash
ros2 run convoy_robot real_leader_bridge_node.py --ros-args -p map_frame:=map -p base_frame:=base_link
```

4. 후발 follower: 모터 단일 소유자, 위치 candidate 발행. 시작은 미무장.
```bash
python3 -B ~/follower_diagnostics/follower_drive_node.py --run-hardware --ack-hardware-zero-rpm-tx --input-kind guard --enable-motion-input --trial-max-rpm 10 --trial-seconds 10
```

5. 후발 follower: 센서/장착TF/위치 기반 실제 EKF. 4번을 먼저 실행.
```bash
ros2 launch ~/follower_diagnostics/follower_position_observation.launch.py enable_position_profile:=true
```

6. 후발 follower: 지도/AMCL
```bash
ros2 launch ~/follower_diagnostics/follower_localization.launch.py enable_localization:=true
```

7. 후발 follower: 최신 입력 QoS를 적용한 bridge
```bash
python3 -B ~/robot_ws/src/cnu_capstone_2026/convoy_robot/real_follower_bridge_tf_candidate.py
```

8. 후발 follower: 추종/보호 (모터 실행부를 별도로 추가하지 않음)
```bash
ros2 launch ~/follower_diagnostics/follower_convoy_preview.launch.py enable_preview:=true
```

9. 후발 follower: gateway, arm을 자동 요청하지 않음
```bash
python3 -B ~/follower_diagnostics/follower_guard_gateway.py --run
```

10. 노트북 로컬: RViz. 처음 한 번 profile을 복사한다.
```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=10
export ROS_LOCALHOST_ONLY=0
scp sunuk@10.253.245.192:/home/sunuk/follower_diagnostics/convoy_view.rviz ~/convoy_view.rviz
rviz2 -d ~/convoy_view.rviz
```

RViz profile은 map fixed frame, 지도 Reliable/TransientLocal,
양쪽 scan/odom/path BestEffort, Grid 한칸1m, TopDown을 미리 설정했다.
선두 초기 위치는 Tool Properties의2D Pose Estimate Topic을 /initialpose로 바꿔 찍고,
후발은 /follower/initialpose로 바꿔 찍는다. 실제 바퀴축 중앙과 실제 정면 방향을 지정한다.
포즈 지정 전/bridge 초기 발견 중 일부 화면이 비어 있을 수 있다.
이후 Ctrl+S로 노트북 profile을 저장하면 다음번에는 scp 없이 -d로 열면 된다.

11. 후발 follower: 조회 전용 확인. 새 SSH 터미널에서 공통 설정 후:
```bash
ros2 lifecycle get /follower/map_server
ros2 lifecycle get /follower/amcl
python3 -B ~/follower_diagnostics/check_follow_start.py --seconds 10
```

지도/AMCL active, motor fault=null/armed=false/feedback_fresh=true/RPM0,
trial_max_rpm=10/trial_max_seconds=10이어야 한다.
초기 path_points=1과 STOP_MISSING_OR_INVALID_PATH는 bridge 재시작 후 정지 중 예상 상태다.
path2개 이상이면 선두 정지 중 STOP_LEADER_STOPPED가 예상된다.
이 기동 순서에는 실제 이동/arm 도구를 포함하지 않는다.
잠금 드라이버/옛 feedback node/선두 개별 직진 도구/Nav2 navigation은 추가 실행하지 않는다.

후발10RPM/10초 제한 직선 추종, 간격 회복·약1.59m 유지,
시간 종료와 Ctrl+C 양쪽 정지 확인. 왼쪽 곡선 진입 첫 시험도 정상 종료했고
사용자는 양쪽이 왼쪽으로 조금 회전했다고 확인했다.

사용법은 POSE_ADJUST_20261101.md 참조. 에이전트가 실제 pose를 발행하지는 않았다.
