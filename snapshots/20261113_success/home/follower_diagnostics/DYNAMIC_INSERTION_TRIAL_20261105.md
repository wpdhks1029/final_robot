현재 결과는 선배치 상자 회피·실제 경로 복귀·추종 1m 확인이며 정량 평가 전체 통과로 취급하지 않는다.
로그의 마지막 주기 경로 오차는 3.26cm/3.40도, 로그 주기 최소 측정 여유는 20.52cm다.
마지막 주기 추종 검증 거리 0.99777m 직후 다음 주기에서 완료 종료되었다.
이후 시험은 완료 순간의 검증 자료도 별도 이벤트로 저장한다.

## 다음 조건

- 시작 배치와 RViz pose를 복원한다. 실제 위치를 움직였으면 지도 위치를 맞춘다.
- 선두 Bridge를 재시작해 이전 시험 경로를 지운다. 유효한 경로가 두 점 이상인지 확인한다.
- 시작 때 상자는 전방 감지 영역에서 빼 둔다. 선발·후발 경로 전방 공간은 확보한다.
- 동일한 --continuous20 실행 명령으로 시작한다. 초기 FOLLOW가 나오는지 확인한다.
- 후발이 약 10cm 진행했을 때 상자를 정면 경로에 투입한다. 투입 작업자는 주행 영역 밖에 있어야 한다.
- 상자는 라이다 높이에 걸리는 20x20cm 장애물, 후발 차체 앞끝에서 약 70cm 앞을 기준으로 한다.
  주행 중 위치가 달라지므로 실제 차량 간 공간에 맞는지 확인한다.
- 연속 스캔 감지 → 정지 확인 → 계획 → 곡선 회피 → map 복귀 → 추종 1m 완료를 확인한다.
- 같은 조건 3회를 개별 로그로 보존한다. 한 번 통과한 결과로 반복 성공이나 평가 전체 통과를 선언하지 않는다.

계획 20cm, 주행 정지 10cm, lookahead 35cm, 4.5m 작업 공간, 입력/모터 감시는 그대로다.
--follow-only는 장애물 감지 시 종료하는 진단 모드이므로 이 시험에 사용하지 않는다.
--near-return-hold도 추가하지 않는다. 근거리 재관측은 연속 모드에 기본 적용된다.

## 투입 작업자 반환점에 대한 정지 후 재계획

연속 모드는 동적 감지 후 양쪽 측정 정지(선두 속도 <=0.01m/s, 후발 fresh 피드백 RPM 0 및 영속도 3회)를 확인한다. 새 스캔 5회와 최소 1.5초 대기 후 전체 점으로 계획한다. NO_VALIDATED_CONTINUOUS_ROUTE 또는 새 스캔으로 경로가 막힌 경우 새 스캔 대기 후 다시 계획하며 총 3회까지만 허용한다. 동적 계획 전체 제한 65초는 유지한다. 오뎀/모터 오류나 계산 예산 초과는 재시도하지 않는다. 사람의 점을 인식에서 제외하거나 가리는 처리는 하지 않는다. 드라이버 재시작은 필요 없다.

## 군집 소실 시 추종 복귀

NO_OBSTACLE_CLUSTER는 즉시 종료 대신 동일한 제한 재계획 대상으로 처리한다. 양쪽 정지 상태의 서로 다른 최신 스캔 5회에서 전방 감지 점수가 5점 미만이고 현재도 그 조건이면 FOLLOW로 복귀한다. 전체 점을 사용하는 주행/이동 영역 검사를 다음 명령에도 그대로 수행한다. 전방 점이 계속 5개 이상인데 군집 조건을 충족하지 못하면 최대 3회 후 종료하며, 센서/모터 오류는 복귀하지 않는다.
