# 최신 지도 공동 사용 전환

사용자는 평가3도 최신 지도로 실행하도록 요청했다. 기존 지도 사용 안내는 이 요청에 적용하지 않는다.
새 선두 지도: /home/sunuk/robot_ws/maps/leader_mapping_20261107_143101_9R24Wc/leader_map.yaml
기존 지도와 성공 백업은 보존한다. 후발에서 scp로 위 폴더를 별도로 복사해야 한다. 현재 도구 환경에서 선두 SSH 접근이 제한돼 파일 복사는 사용자가 수행해야 한다.
후발 follower_localization.launch.py에 map:= 인수를 추가했다. 기본 기존 지도 해시 검사는 유지하며, 새 지도는 명시적 경로와 YAML/이미지 검증 및 SHA256 로그를 사용한다. 양쪽 AMCL에 동일 지도 복사본을 지정하고 초기위치와 선두 Bridge 경로 이력을 새로 설정한다.
RViz의 지도 표시를 하나만 선택하는 것과 실제 양쪽 지도 일치는 별개다.
회피 시험의 기본 reference-plan은 옛 지도 좌표이므로 새 지도 시작선 기준을 별도 생성/검증해야 한다. 단순히 YAML 경로만 바꿨다고 기존 평가3 명령으로 즉시 출발하지 않는다.
실물 최신지도 시험은 미실시. 지도 선택 검증4개 및 구문 검사 통과.
