# 장시간 단계1: 60초 고정 상한 시험

기본5초와 기존10/30초 모드는 유지한다. 명시적인 --trial-seconds 60만 추가했다. 무기한 모드·원격 갱신·자동 재arm은 추가하지 않는다.

후발 드라이버60초 고정 마감(포트 게이트에도 동일 마감), 감독도구는arm 후59.5초 양쪽정지요청, 선두 출발부터64초 상한. 새 명령을 계속 받아도 기존 마감은 연장되지 않는다. 최초 전방유효조건 대기는 기존4초다.

속도0.04/0.05, RPM3/5/10 선택과 기본값, 0.3초 원본/명령/응답 기한, epoch·비무장·오류잠금·장애물 보호는 변경하지 않았다. 첫 실물시험은 선두0.04/후발10RPM/직진60초를 사용한다. 명령상 선두이동거리는 약2.4m이며 실제이동량·직진편향·정지여유는 이 값으로 보장하지 않는다.

60초 모드에서는 타이밍 기록 메모리 한도를6000행에서12000행으로 늘려 앞부분이 잘리는 것을 줄였다. 실제쓰기시점은 기존대로 정지확인후다.

검사: 드라이버/모터/게이트웨이/감독/감독흐름 메모리 테스트100개통과. 추가검사는60초 고정만료, 포트자체만료,45초명령소실, 드라이버30/감독60불일치거부, 감독59.5초정지와단일arm이다. 실제60초하드웨어 정지 검증은 아직 하지 않았다.

백업 backups/follow_60s_20261102/.

## 적용

후발 드라이버 터미널만 Ctrl+C 후:

```bash
python3 -B ~/follower_diagnostics/follower_drive_node.py --run-hardware --ack-hardware-zero-rpm-tx --input-kind guard --enable-motion-input --trial-max-rpm 10 --trial-seconds 60
```

별도 터미널에서:

```bash
python3 -B ~/follower_diagnostics/run_joint_follow_trial.py --run --ack-clear-both-power-cut-ready --trial-seconds 60 --leader-speed 0.04 --leader-turn straight --trace-timing
```

START 안내 후30초 수신대기. 실제 경로·주변여유·전원차단준비를 확인한 뒤 START. 보호정지하면자동재출발하지않는다. 다른노드/EKF/pose는변경하지않는다. 뒤쪽반사판 사용여부와실물간격변화를결과에함께남긴다.

## 되돌리기

드라이버와시험도구 양쪽 --trial-seconds를30으로 맞춘다. 코드롤백 없이 기존30초방식으로 동작한다. 기준문서의기본시연상한은30초로유지하며60초실물결과가나오기전통과로표시하지않는다.


첫 실물60초시험 결과: joint_follow_trial_1793624770758235598.jsonl 판미사용, 추종약42.08초뒤선두/경로수신공백약.263초에원본유효나이.301초로보호정지. 양쪽영속도/오류없음.60초완료는아니며시간제한이나TTL을완화하지않았다.


휴대폰을올려둔조건의실물시험: joint_follow_trial_1793627445739160815.jsonl 추종59.5초, 시간만료/양쪽영속도/오류없음. 위치높이와거리미기록. 단일성공이므로배치의인과관계나일반환경완료로확정하지않는다.
