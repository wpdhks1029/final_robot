## 실물 확인 완료

USB를 하나씩 분리 후 같은 자리에 복원해 확인했다.
by-path 공통 앞부분: /dev/serial/by-path/platform-fd500000.pcie-pci-0000:01:00.0-usb-0:

| 장비 | 경로 끝부분 | 당시 장치 |
|---|---|---|
| MD200T | 1.4:1.0-port0 | ttyUSB0 |
| G2B LiDAR | 1.1:1.0-port0 | ttyUSB1 |
| iAHRS IMU | 1.3:1.0-port0 | ttyUSB2 |

CP2102 두 장치의 시리얼0001이 중복되어 by-id 구분 불가. USB 소켓 변경 시 재확인.

- MD200T: 19200bps, ID1, M1 왼쪽/M2 오른쪽.
- 바퀴 지름130mm -> 반지름0.065m, 윤거0.560m.
- M1 양수 명령은 실제 후진, M2 양수 명령은 실제 전진.
- 따라서 invert_left=true, invert_right=false. 명령/피드백에 같은 좌측 반전 필요.
- base_link 원점: 바퀴축 중앙의 바닥 투영점. +X 차체 전방, +Y 좌측, +Z 위.
- IMU xyz=(0,0,0.16)m, rpy=(0,0,0), 선두와 같은 장착 방향이라고 사용자 확인.
- LiDAR xyz=(0.26,0,0.24)m, 최종 rpy=(0,0,0).

## 진단 파일과 실행 방법

모든 옵션 기본 false. 기존 launch/standalone 노드를 종료한 뒤 하나만 실행한다.
시리얼 포트당 소유자는 하나. PID4 관측 노드와 속도시험 스크립트 동시 실행 금지.
관측 launch에는 속도 제어기/STOP 기능이 없다.

```bash
source /opt/ros/humble/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=10
export ROS_LOCALHOST_ONLY=0

# LiDAR/센서TF만. 모터/IMU/EKF 없음. 최종 방향 기본값 사용.
ros2 launch ~/follower_diagnostics/follower_observation.launch.py \
  enable_sensor_tf:=true enable_lidar:=true

# 필요 시 선택하는 전체 무구동 관측. 실제 PID4/IMU 질의 및 RX 로그 기록이 발생한다.
# 위 launch와 동시에 실행하지 않는다.
ros2 launch ~/follower_diagnostics/follower_observation.launch.py \
  enable_sensor_tf:=true enable_lidar:=true \
  enable_imu:=true enable_feedback:=true enable_ekf:=true
```

EKF 원본은 src/cnu_capstone_2026/config/follower_ekf_A_selected.yaml 그대로다.
주파수30Hz, odom vx/vy/yaw-rate 및 IMU yaw-rate 융합. map 위치는 생성하지 않는다.
