# 평가 2: 선두 단독 3m 전진·후진

기존 선두 코드는 보존한다. 별도 디렉터리에 설치하며, 설치는 모터를 구동하지 않는다.

후발에서 설치:

```bash
python3 -B ~/nav2_follow_stabilization/evaluation2/deploy_leader_candidate.py --apply
```

출력 LEADER_DIR 안의 forward_3m.bash 또는 reverse_3m.bash를 선두에서 bash로 실행한다.
실행 후 입력 점검을 통과하면 START + Enter를 입력해야 이동한다.

선두 모터·센서·EKF 터미널은 유지한다. 선두 Nav2/gate 터미널, 후발 추종
프로그램 및 모든 teleop을 중지한다. 지도·AMCL·브릿지·중계기는 유지 가능하다.
후발은 비무장 상태이며, 후진 3m 경로에서 물리적으로 치운다.

최대 속도 ±0.1m/s, 종료 전 마지막 0.1m는 ±0.02m/s이다. 시작 방향으로
투영한 /odom 이동량이 3m가 되면 정지한다. 실제 거리·편차는 별도 측정한다.
이 시험은 Nav2 Goal이 아닌 선두 단독 거리 시험이다. 곡선 추종이나 후발 동작은 수행하지 않는다.

독립 시험 시간 한도 60초는 모터 명령이 계속되는 고장을 제한하기 위해 유지한다.
센서 지연 0.3초, 15도 방향 이탈, 15cm 횡방향 이탈, 반대 이동, 중복 명령 발행자,
LiDAR 주변 공간 위반 시 종료한다. 기본 명령은 라이다 검사를 유지한다.
정지 후 새 오뎀 5개에서 정지 상태를 확인한다. Ctrl+C도 정지 명령을 보낸다.
실제 기체 시험은 수행하지 않았다. 모의 ROS에서 양방향 목표 거리, 정지,
중복 명령 거절, 입력 지연·장애물·Ctrl+C 정지를 검증했다.

## 전진 거리 보정: 2026-11-13

실측 전진 2.80m / raw odom 3.006033022m에서 전진 거리 계수
0.9314601601121597을 산출했다. 실측은 출발·도착에서 동일한 차체 지점을
사용했다고 가정한다. forward_3m.bash만 이 계수를 전달한다.
보정 후 목표는 raw odom 약 3.220750m이며, 속도 명령은 기존 최대 0.1m/s를 유지한다.
오뎀 발행·EKF·추종·모터 EEPROM 설정은 변경하지 않는다.
후진 계수는 실측이 없으므로 1.0을 유지한다. 1회 실측에 기반한 잠정 보정이며
반복 실측으로 검증해야 한다. 결과의 estimated_calibrated_progress_m는
보정 추정값이지 독립 실측이 아니다. 기존 원본 distance_sources도 그대로 기록한다.
보정 전 코드는 ../backups/evaluation2_before_distance_scale_20261113에 보존했다.
현재 설치 폴더는 ~/leader_diagnostics/eval2_distance_74ad51756f26이다.

## 평가 2 차체 내부 점 제외

전진·후진 모두 라이다 점을 장착 TF로 base_link 좌표로 변환한 뒤,
abs(x)<=0.27m 및 abs(y)<=0.30m인 점만 장애물 검사에서 제외한다.
차체 경계 밖으로 제외 범위를 늘리지 않았다. 이는 기존 코드의 차체 치수 가정이다.
외부 점에는 기존 0.3m 여유를 포함한 원형 공간 검사를 계속 적용한다.
외부 유효 점이 100개 미만이면 공간 확보를 입증할 수 없으므로 시작/진행하지 않는다.
입력 시각·장착 TF·기기 명령 소유권·거리·시간·정지 검사는 유지한다.
last_scan_evidence에 제외한 점 수와 최대 8개 좌표를 기록하고 원본 스캔도 보존한다.
사용자 로그의 실제 장착 yaw=-180도, range=0.255m 점이 변환 후 제외됨을
검증했다. 모의 실행 14개와 설치 시뮬레이션 1개를 통과했다. 실제 모터는 구동하지 않았다.
수정 전 원본은 ../backups/evaluation2_before_body_mask_20261113/sources.tar.gz에 보존했다.

## 평가 2 속도 0.3m/s

전진·후진 실행 스크립트는 최대 속도 0.3m/s를 요청한다. 0.3 모드만
가속 0.2m/s², 감속 0.3m/s²에 따른 속도 변화를 적용하며 목표 전 0.1m는 0.02m/s로 접근한다.
거리·차체 내부 제외·외부 장애물·센서·Ctrl+C 정지 조건은 유지한다.
보정은 전진 계수 0.93146016011216, 후진 1.0이다.

기존 보관 선두 launch의 max_rpm=25는 반경 0.085m에서 약 0.223m/s 상한이다.
새 leader_eval2_speed030.launch.py는 기존 ~/leader_diagnostics 의 센서·드라이버·EKF
소스를 읽고 max_rpm=35를 전달한다. 기존 소스를 덮어쓰지 않는다.
평가 2 전용이며 정상 추종 때는 기존 leader_nav_yaw_calibrated.launch.py를 사용한다.

새 번들 설치 후 선두 기존 모터·센서·EKF 터미널 1을 중지하고:

```bash
ros2 launch ~/leader_diagnostics/eval2_distance_74ad51756f26/leader_eval2_speed030.launch.py allow_motion:=true
```

중복 실행하지 않는다. 오뎀 재시작 후 선두 AMCL을 사용하려면 RViz에서 선두 위치를 재설정한다.
Nav2/gate와 후발 추종·teleop은 중지한 채 새 폴더의 forward_3m.bash / reverse_3m.bash를 실행한다.
이전 버전은 ../backups/evaluation2_before_speed030_20261113에 보존했다.
실제 기체 구동과 0.3m/s에서의 거리 실측 검증은 수행하지 않았다.

## 전진 추가 거리 보정

운영자가 앞선 주행도 실측 2.90m였다고 보고해, 전진 계수를
0.93146016011216 × 2.9/3 = 0.900411488108421로 변경했다.
전진 raw odom 목표는 약 3.331810m가 된다. 속도는 전진 0.1m/s,
후진 0.3m/s이며 후진 거리 계수는 변경하지 않는다.
이 보정은 실측 보고에 기반한 잠정값이다. 최근 ROTATION_CIRCLE_NOT_CLEAR로
끝난 시험의 거리 부족을 목표 도달 오차로 간주한 것은 아니다.
외부 장애물 정지는 유지되므로 동일 물체가 있으면 목표 전에 정지할 수 있다.
현재 폴더: ~/leader_diagnostics/eval2_distance_dbd45e9d9025
이전 전진 스크립트와 보정 기록은 ../backups/evaluation2_before_extra_forward10cm_20261113에 보존했다.

## 전진 실측 3.10m 추가 보정

현재 계수 0.900411488108421 × 3.1/3 = 0.930425204378702로 조정했다.
전진 요청 오뎀 거리를 3/3.1배로 줄인다. 후진 설정은 보존한다.
최근 운영자가 사용한 --operator-clear-path 모드를 전진 스크립트에도 반영했다.
기존 배포 코드도 --distance-scale 인자로 새 계수를 사용할 수 있어 재복사 없이 실행 가능하다.
실측에 기반한 잠정값이며 재시험이 필요하다.

## 3회 합계 9.05m 보정

직전 계수 0.930425204378702로 실행한 3회 합계가 9.05m였다는 보고에 따라
새 계수 0.935594233291917 = 이전 계수 × 9.05/9를 적용했다.
회당 오뎀 목표 3.206518267m. 전진만 변경하며 후진은 보존한다.
세 번 모두 같은 설정과 같은 차체 기준점으로 측정했다고 가정한다.

## 후진 0.5m/s 평가 후보

사용자 요청으로 후진만 최대 0.5m/s로 변경했다. 0.5는 전진 모드에서 거절한다.
전진은 0.1m/s와 계수 0.935594233291917을 유지하고, 후진 거리 계수는 1.0이다.
후진 가속 0.2m/s², 감속 0.3m/s² 제한과 도착 전 감속을 유지한다.
reverse_3m.bash에도 사용자가 선택한 --operator-clear-path 모드를 적용했다.
라이다 정지는 사용하지 않으며, 오뎀·IMU 시각 검사, 방향/횡방향 이탈,
시간 한도, 정지 확인과 단일 명령 발행자 검사는 유지한다.

현재 설치 폴더: ~/leader_diagnostics/eval2_distance_0b10ece7e961
선두 기존 터미널 1을 종료하고 새 leader_eval2_speed050.launch.py를
allow_motion:=true로 실행한다. 중복 드라이버 실행은 금지한다.
새 launch만 max_rpm=57을 전달하며 기존 소스·설정 파일을 덮어쓰지 않는다.
반경 0.085m 기준 0.5m/s 명령에 약 56.17RPM이 필요하다.
Nav2/gate·후발 추종·teleop은 종료하고 후방 경로를 확인한 뒤 시험한다.
실제 0.5m/s 속도와 정지 거리·거리 정확도는 아직 검증하지 않았다.
