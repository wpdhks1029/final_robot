## 판정

모터 피드백 기반 raw odom의 단기 적분은 내부적으로 일관됨.
EKF 출력 위치가 불연속적으로 변하므로 지상 Nav2 주행 검증은 보류.
첫 스크립트의 7.5313m와 공통 구간 분석의 7.4392m는 서로 다른 표본 경계에서
산출한 값이다. 두 분석 모두 비정상적인 큰 EKF 위치 변화를 보여준다.

## 원인 후보와 한계

확인된 공분산 상태는 비정상적으로 크고, 입력 신뢰도는 유효 시 0과 stale 시
1e6 사이에서 전환됨. 현재 EKF 입력은 wheel vx와 IMU yaw/yaw-rate이며
wheel vy=0 제약은 사용하지 않음. 필터의 장시간 미관측 상태/공분산 성장과
새 속도 관측의 위치 보정이 관련됐을 가능성을 우선 조사한다.

단, rosbag에는 15x15 전체 필터 공분산과 혁신/게인이 없고 필터 초기화 전부터의
전체 이력도 없다. 공분산 비대칭은 별도 결함 후보지만 vx만 선택하는 현재 입력에서
이 항목이 위치 점프를 직접 유발했다고 확정하지 않는다.
RPM 변환·wheel_track·IMU 스케일을 변경할 근거도 아직 없다.

   소프트웨어 시험. 재생 토픽은 /odom, /imu/data, /tf_static으로 제한하고
   /cmd_vel과 기존 EKF 출력/동적 TF는 재생하지 않음.
3. 기존 설정의 신규 필터와 기존 기록의 누적 상태를 비교.
4. 후보 공분산/비홀로노믹 제약은 별도 진단 설정에서만 비교하며,
   성공 설정이나 모터 제어 코드에 곧바로 적용하지 않음.
