# 최우선 작업: 후발 장애물 우회·재합류

사용자 우선순위: 평가3 먼저. 선두Nav2의평가1/2작업은보류한다. 지금까지완료한단순정지와PurePursuit주행을회피성공으로표시하지않는다.

## 실제 개발 조건

최종정정치: 장애물 바닥면20×20cm, 원래높이20cm. 라이다중심은바닥에서실측25cm. 사용자가시험물높이를스캔평면보다높게맞출예정이라고확인했다. 공간폭약2.5m. 40cm상자/3m공간가정은폐기한다. 원래20cm정육면체의정면면적은.04m²이며보고서.2m²와구분한다. 높이조정후시험물치수는별도기록한다.

현재차체폭.60m,앞뒤각.27m,전방향hard여유.30m를유지한다. 통과평행구간에필요한폭의하한은.60+2*.30=1.20m다. 상자를폭2.5m정중앙에두면한쪽틈1.15m로현재여유에부족하다. 상자중심을공간중심에서왼쪽.15m로옮기면오른쪽틈1.30m가된다. 이는정적인평행통과기하하한일뿐회전중전체차체가통과한다는보장이아니다.

## 이번 구현

- apf_case3_candidate.py: 순수APF계산후보. 차체외곽거리사용,하드여유침범시정지,회피방향고정으로좌우진동억제,전진휠조건v>=|w|*track/2보존. 입력명령0이면가상회피명령도0. 실제관측확인없는작은시험물은감지가능하다고취급하지않는다. 선두마스크/광학점삭제/기존보호기준변경없음.
- RejoinEvidence: 실측직선기준·장애물후단을입력받아네차체모서리전체통과,재합류,이후순진행1m를따로계산. 재이탈·후퇴는진행증거초기화. 반환값은기하후보이며contact_observation_required=true/evaluation_pass=false다. 물리적접촉판정과외부관찰을대체하지않는다.
- watch_apf_case3.py: 실제scan/실제TF를받아가상전진.04m/s입력의계산결과만출력·저장. ROS명령발행/모터/arm서비스접근없음. 기존추종/guard/gateway/드라이버와연결하지않았다. 재합류증거는아직이관찰노드에연결하지않았다.
- 알고리즘가중치와재합류허용값은설계후보이며튜닝/실물검증전이다. 보고서에없는횡오차허용값을임의의정식합격기준으로삼지않는다.

검사20개통과: 입력기하,장착TF,근접정지,진행방향보존,중앙대칭장애물조향,방향고정,뒤차체통과,재합류후1m,이탈/후퇴증거초기화등. 실제우회주행은아직검증하지않았다.

## 정지 관찰 절차

양쪽로봇정지상태와기존노드유지. 시험물높이를실제스캔평면위로맞춘뒤,폭2.5m공간중심보다왼쪽15cm에상자중심배치. 후발차체앞끝에서상자앞면까지약.6~.8m. 다음조회만실행한다:

```bash
python3 -B ~/follower_diagnostics/watch_apf_case3.py --seconds 60 --confirm-obstacle-visible --obstacle-center-y 0.15
```

가상후발명령의w<0이면이배치에서오른쪽회피계산이다. 실제로는움직이지않는다. STOP_FOOTPRINT_CLEARANCE는그대로기록한다. 계산관찰이끝난뒤스캔·회피방향·근접여유를확인하고모의궤적/보호체인검증을진행한다. 이조회성공을평가3통과로표시하지않는다.
