# 현재 모드: 주행 중 나타난 상자 회피

성공 백업을 바탕으로 `--dynamic-box` 모드를 추가했다. 상자 없이 FOLLOW로 시작하고, 후발 차체 앞면에서 전방 70cm·좌우 65cm 이내 점이 5개 이상인 서로 다른 스캔 3개를 확인하면 PLAN_BRAKE로 전환한다. 양쪽 정지 후 후발 바퀴 정지 피드백을 확인하고 곡선 경로를 한 번 계산한다. 현재 스캔으로 검증한 경로만 실행하며, 지도 경로 합류 후 Pure Pursuit 추종으로 전환한다.

계획 여유20cm, 주행 정지10cm, lookahead35cm, 최대10RPM. 추가 장애물에 대한 무한 반복 재계획은 없다. 계산 실패나 센서/모터 이상은 정지 종료한다. 70cm는 감지 거리이고, 그 거리에서 모든 상자 배치에 우회 경로가 존재한다는 뜻은 아니다.

곡선 경로 계획에서는 상자 추출만 공유하고, 예전 제자리 회전 34cm 검사에 의존하지 않는다. 모든 실제 곡선 후보의 충돌 검사/오프라인 재현 검사는 유지한다.

드라이버는 성공 백업 버전 그대로다. 앞선 안내대로 드라이버를 이미 재시작했다면 이번 변경만으로 다시 시작할 필요는 없다.

```bash
python3 -B ~/follower_diagnostics/run_local_avoidance_trial.py \
  --run \
  --ack-clear-both-power-cut-ready \
  --apf-pivot \
  --gentle-pivot \
  --map-rejoin \
  --continue-follow-after-rejoin \
  --continuous20 \
  --dynamic-box \

```

시작 시 FOLLOW 모드인지 확인한다. 초기 배치/지도 pose/선두 경로는 여전히 유효해야 한다. 상자 없이 시작하고 주행 중 나타난 상자를 검사한다. `--plan-only`에서는 연결과 초기 입력만 확인하며 아직 나타나지 않은 상자의 우회 경로를 검증하지 않는다. 실물 주행은 미검증이다.
