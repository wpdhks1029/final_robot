# APF 초기 조향 연결 후보

## 후속 직선 통과·재합류 후보 (2026-11-03)

사용자가 5초 실물 시험에서 오른쪽 초기 조향과 양쪽 정지를 확인했다.
`enable_rejoin:=true`는 별도 선택이며 기본값 false다. 현장 통과/재합류는 아직 검증하지 않았다.
직선 경로·알려진 20cm 정적 상자만 대상으로 한다. 새 경로 생성 없이 측방 가상 목표에 대한 인력과 스캔 반발력을 사용하고, 통과 후 원래 직선 인력으로 복귀한다.

- 실제 /follower/odom_map과 /leader/path의 기하·프레임 검증 및 원본/수신 0.3초 만료. 원격 path stamp는 50ms 보수 여유 유지.
- 네 모서리 통과 뒤 추가 .45m 회전 여유 확보. 현재 스캔 기반 1초 차체 검사와 기존 .30m 정지/.60m 감속 그대로 적용.
- 위치 점프 .15m 초과 잠금, 곡선 기준/경로 이탈 거부. 이 값은 후보 설계 한계이며 보고서 평가 합격 기준이 아니다.
- 재합류 위치오차 .10m, 방향오차 10도는 개발 관찰 허용값. 재합류 후 순진행 1m 증거를 분리하며 접촉 여부는 외부 관찰 필요.
- 후보는 1.5m 여유 거리부터 APF 반응. 기존 초기 조향 모드의 .9m 범위는 변경하지 않았다.

현재 앞끝~상자 .77m, 중심 왼쪽 .15m의 가상 실험은 완전 통과/복귀 전 여유 한계에 걸렸다. 이 배치를 전체 회피 가능하다고 보장하지 않는다.
다음 개발 배치는 앞끝~상자 약1.3m, 상자 중심 공간중심 왼쪽 .35m: 오른쪽 평행 틈1.50m. 더 큰 회전 공간을 얻는다.
이상적인 정적 기하 모의는 실물·가림·마찰·지연 검증을 대체하지 않는다. 모든 점검은 모터/ROS 명령 없이 수행했다.
기존 감속 유지 시 전체 통과·재합류·1m에는 60초보다 오래 걸릴 수 있다. 시간 제한을 자동 해제하거나 드라이버를 변경하지 않았다.

새 후보 선택은 기존 APF 터미널 종료 뒤 launch 인자 `enable_rejoin:=true obstacle_center_y:=0.35`로 한다.
단계별 짧은 시험부터 진행하며 기존 5초 초기 조향 성공을 전체 평가3 성공으로 표기하지 않는다.

보고서의 Pure Pursuit + APF 유지. 별도 경로 계획기는 추가하지 않았다.
후보 launch만 명시적으로 APF를 활성화한다. 기존 follower_convoy_preview.launch.py의 실행 방식은 유지한다.

제어 순서: Pure Pursuit → APF → 기존 전방향 30cm 정지/60cm 감속 → 현재 스캔 기준 1초 사각 차체 검사 → 기존 stamped guard → Gateway → 비무장 시작 드라이버.
원본 source stamp와 0.3초 만료 검사는 보존한다. APF는 arm/모터 서비스에 접근하지 않는다.
1초 검사는 정적 관측점에 대한 후보 검사이며 동적 장애물이나 전체 우회 경로의 안전을 증명하지 않는다.

이번 후보는 초기 조향 단계에 한정된다. PASS/REJOIN에서는 STOP_APF_REJOIN_NOT_CONNECTED로 정지한다.
통과/재합류 실물 검증이나 평가3 완료로 표시하지 않는다. 재합류 상태와 실제 pose 증거의 제어 연결은 후속 작업이다.
공간/장애물 기하 및 스캔 높이 확인값을 사용하는 제한된 시험 후보다. 현장 벽 위치의 자동 인식/통로 폭 추정은 아직 아니다.

기존 터미널5를 종료한 뒤 대체 실행:

```bash
ros2 launch ~/follower_diagnostics/follower_convoy_apf_candidate.launch.py \
  enable_preview:=true \
  confirm_obstacle_visible:=true \
  obstacle_center_y:=0.15
```

기존 preview와 동시 실행 금지. 시작은 비무장 상태에서 확인한다.
복귀는 후보 launch 종료 후 기존 follower_convoy_preview.launch.py enable_preview:=true 실행.

APF/기존 장애물 보호/stamp/Gateway/launch 관련 단위 검사 68개 통과.
실제 로봇, 시리얼 포트, arm, 주행 명령은 개발 도구에서 실행하지 않았다.
