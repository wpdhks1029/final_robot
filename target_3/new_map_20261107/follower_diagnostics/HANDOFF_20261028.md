## 현재 실행 구분 — 다음 세션 재확인

사용자가 이 노드들을 실행한 상태였다. 도구가 현재생존을 직접 확인한 것은 아니다.
터미널 A 관측, B 조회, C 위치추정, D 후발bridge, E 시험추종으로 구분한다.

```bash
# 각 후발터미널 공통
source /opt/ros/humble/setup.bash
source ~/robot_ws/install/setup.bash
export ROS_DOMAIN_ID=10
export ROS_LOCALHOST_ONLY=0

# A: 센서/static TF/조회전용MD/EKF. 실제속도제어 없음.
ros2 launch ~/follower_diagnostics/follower_observation.launch.py \
  enable_sensor_tf:=true enable_lidar:=true \
  enable_imu:=true enable_feedback:=true enable_ekf:=true

# C: 지도/AMCL/lifecycle manager
ros2 launch ~/follower_diagnostics/follower_localization.launch.py enable_localization:=true

# D: map pose interface. 속도제어 없음.
python3 -B ~/robot_ws/src/cnu_capstone_2026/convoy_robot/real_follower_bridge_tf_candidate.py

# E: 새 시험추종. 출력 /follower/cmd_vel_test 고정,실제모터연결금지.
python3 -B ~/follower_diagnostics/follower_pursuit_preview.py
```

선두도 기존성공경로에서 base allow_motion=false,localization,초기위치지정,bridge를 사용자가 실행.
Nav2 navigation은 켜지 않도록 안내했다. 선두모터는0RPM/피드백통신을 하므로
allow_motion=false도 무송신이 아니다. 추가모터구동은 임의실행금지.
