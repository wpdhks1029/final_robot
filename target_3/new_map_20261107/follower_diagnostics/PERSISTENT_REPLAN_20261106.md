# 추가 장애물: 정지 유지하며 재계획

명시적 --persistent-replan 옵션을 continuous20 회피 모드에 추가했다. 기존 명령의 제한 재시도 모드는 유지한다.

- 주행 중 현재 차체 또는 예측 이동 영역/남은 회피 경로가 막히면 두 로봇에 0 명령을 요청하고 OBSTACLE_WAIT로 들어간다.
- 운용자는 arm 세션을 유지하되 바퀴에는 계속 0 명령을 보낸다. 자동 재무장이나 오류 해제는 없다.
- 양쪽 측정 정지, 새 입력의 유효기간 및 후발 영속도 3회를 확인한 뒤 새 스캔으로 비동기 재계획한다. 최신 스캔의 모든 점과 원래 알고 있던 상자 경계를 포함한다.
- 후보는 정수 RPM 모델 재생과 최신 스캔의 경로 검사를 통과해야 설치한다. 설치 뒤에도 서로 다른 5개 스캔에서 재개 여유를 확인한다. 확인 완료 주기는 0 명령이며 다음 주기부터 다시 현재 이동 영역 검사를 거쳐 가속한다.
- 장애물이 없어져 기존 경로가 다시 유효하면 같은 5개 스캔 확인 후 기존 경로로 재개할 수 있다.
- 계획 실패 3회나 기존 근거리 반환 대기 2초만으로 세션을 종료하지 않는다. 각 계산은 최대 60초이며 전체 시험 360초 제한은 유지한다. 경로를 찾지 못하면 0 출력을 유지한다.
- 입력 유효기간 0.8초, 모터 watchdog, map/오뎀 급변, 경로 이력/역방향 검사, 작업 공간 제한, Ctrl+C 종료는 그대로다. 이런 오류는 장애물 대기로 바꾸지 않는다.
- 모든 장애물 배치에서 우회 경로를 찾는다는 보장은 없다. 후보 생성기는 왼쪽 우회 중심의 제한된 곡선 집합이다. 안전한 후보를 못 찾으면 남은 시험 시간 동안 정지한다.

계획 목표 20cm, 현재/예측 정지 최소 기준 10cm, 회피 트리거 차체 앞끝 70cm를 유지한다. 연속 곡선 플래너를 상자 추출과 분리해 이전 APF의 34cm 제자리 회전 사전 검사에 종속되지 않도록 했다. 차체 내부 점은 계속 거부한다.

실행: 기존 continuous20 명령에 --persistent-replan을 추가한다. 드라이버 재시작은 필요 없다. 관찰 도구는 OBSTACLE_WAIT도 구간으로 기록한다. --follow-only와는 함께 쓰지 않는다.

실물 검증은 아직 하지 않았다. evaluation_pass는 false로 유지한다.

## START 직후 경로 변화

START 후 출발 재검사에서 경로가 막히면 persistent 모드는 비무장 상태로 새 스캔과 경로를 재검사한다. 막혀 있으면 비동기 재계획하고, 최신 스캔 5개에서 검증된 뒤에만 선두 출발/후발 arm 단계로 진입한다. 로봇 pose가 3cm/약 2.9도 이상 변하거나 입력/모터/그래프 조건이 깨지면 종료한다. 출발 전 대기는 최대 설정 시험 시간(현재 360초)이며, 실제 주행의 별도 360초 제한도 유지한다. START 동의는 같은 배치·모드에서만 유효하게 유지한다.
