# 실물 시험 중단 로그와 수정

- joint_follow_trial_1793708139132813142.jsonl: 정지 직전 DETOUR_READY, 경로 여유 하한 0.32299m, 현재 차체 여유 약0.365m. 이후 STOP_SCAN_OR_TF_INVALID 출력(source=0)로 supervisor GUARD_SOURCE_OR_RX_INVALID. 당시 예외 세부를 저장하지 않아 미래 TF 외삽인지 다른 scan/TF 오류인지는 확정 불가.
- joint_follow_trial_1793708202393176609.jsonl: 진단 429개 모두 STOP_SESSION_FINISHED. 이전 세션 종료 노드를 재사용해 출발 대기4초 만료, 후발 arm 없음. 30초 한계는 arm 후 계산.

수정:
1. 스캔 시각의 TF가 미래 외삽 오류로 아직 도착하지 않았을 때 최신 스캔 1개를 보관하고 타이머에서 비차단 재시도한다. 그동안 직전에 검사한 스캔은 원래 측정/수신 시각 그대로 0.3초 안에서만 사용. 과거 TF 오류, 프레임/기하 오류, 순서 역전, 만료는 무효 처리. 최신 TF나 현재시각으로 대체하지 않는다.
2. pending_scan_source_ns와 scan_tf_detail을 진단/시험 로그에 저장해 실제 예외 확인 가능.
3. 종료된 세션, 위치 급변, 초기 위치 불일치 등은 supervisor가 선두 출발 전에 중단한다. 자동 세션 초기화/재무장 없음. 매 시험 전 임시 경로 제어 프로세스를 재시작해야 한다.

관련 제어 검사 19개 통과. 기존 운용 흐름 검사도 통과. 실제 ROS TF 지연 조건에서 새 코드의 주행 성공은 아직 검증하지 않았다. 드라이버/제어/운용 도구30초 및 10RPM/원본시간0.3초/차체30cm 보호 유지.
