# 임시 경로 30초 시험

사용자 요청으로 임시 경로 시험을 30초까지 허용한다. 기본값 5초는 유지한다.

새 모드 TEMPORARY_DETOUR_BOUNDED_V2. 제어 노드 --trial-seconds 30 --ack-bounded-trial, 드라이버 --trial-seconds 30, 시험 도구 --temporary-detour --trial-seconds 30 모두 일치해야 한다. 기존 --ack-5s-only는 5초에만 유효하다.

운용 도구 후발 29.5초 제한, 제어 노드 무장 관찰 후 29.75초 제한, 모터 드라이버 독립 30초 제한. 선두 출발 후 전체 34초 상한. 원본/수신 시간 0.3초, 30cm 정지/60cm 감속, 매 스캔 남은 경로 검사, 회전 차체 검사, 10RPM 상한, 위치 급변/선두 정지/세션 종료 차단 유지. 선두는 0.04m/s 직진 고정이며 협조 감속은 연결하지 않는다.

현재 정지 장면의 고정 경로를 사용한다. 주행 도중 관측점이 경로를 막거나 입력이 만료되면 30초 이전에도 정지한다. 30초 완료는 전체 장애물 통과·재합류 평가의 성공을 뜻하지 않는다. 실제 모터를 통해 새 30초 모드를 실행하지 않았다.
