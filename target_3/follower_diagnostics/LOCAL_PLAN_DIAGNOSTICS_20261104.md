# 로컬 회피 경로 생성 실패 대응

실패 로그 local_avoidance_trial_1793769192652805653.jsonl은 STOP_NO_CHECKED_STOP_TURN_GO_ROUTE이며, 선두 출발/후발 arm 모두 없었다. 이 버전은 고정 후보6개만 확인하고 실패 스캔을 저장하지 않아 실제 차단 물체를 해당 로그로 판정할 수 없다.

수정: 기존6개 후보를 먼저 확인한 뒤 현재 관측 상자 옆면과 여유를 반영한 좌측 오프셋, 초기 전진거리0~32cm, 후단 복귀 여유75~115cm 후보를 추가 탐색한다. 전체 회전 차체 검사와 원본 관측점은 유지한다. 탐색은8초 이내로 제한하며, 시간 소진 시 이를 진단에 표시한다. 이를 모든 가능한 경로의 불가능 증명으로 해석하지 않는다.

계획 작업을 시작하기 전에 planning_input 이벤트로 전체 현재 관측점/시작 자세/원본 시각을 저장한다. 실패한 각 후보의 최소 여유, 차단점, 차체 자세/경로 인덱스도 planning_failed 이벤트에 보존한다.

조회 명령:

```bash
python3 -B ~/follower_diagnostics/run_local_avoidance_trial.py --plan-only --seconds 30
```

이 모드는 모터 명령·선두 속도 발행자를 만들지 않고 arm/disarm 서비스를 호출하지 않는다. 현재 후발 드라이버는 local_avoidance, 30초, 입력0.8초로 켜두며 센서·위치추정·Bridge도 유지한다. 다른 시험 도구는 종료 상태여야 한다. 성공 시 PLAN_JSON에 검사된 현재 계획을 저장한다. 저장된 계획을 물리 제어 허가로 사용하지 않으며 --run은 현재 스캔을 다시 검사한다.

검증7개 통과: 기존6개가 전부 차단되는 합성 장면에서 추가 후보 성공, 내부점이 있는 경우 차단 유지 및 실패점 보존, 조회 모드의 제어 발행자/arm/선두 출발 없음, 기존 운영·입력 손실 정지 회귀.
