# 정수 RPM 재가속 검사 수정

대상 로그: logs/local_avoidance_trial_1793946332876069746.jsonl
재계획 후 저속 램프에서 CONTINUOUS_RAMP_WARMUP 다음 STOP_WHEEL_BOUND로 종료됐다. 기존 로그는 정확한 후보 RPM을 저장하지 않아 해당 명령값 자체는 확정할 수 없다.

재현: v=0.003m/s, w=0.024rad/s 정도에서는 반올림 결과 바퀴 RPM이 [-1,+1]이 되어 순전진 qv=0이 될 수 있다. 실제 피벗을 허용하지 않는 기존 검사에서 이 상황도 한계 오류로 종료했다.

수정:
- qv=0이면 반대 방향 동일 RPM도 포함해 실제 v/w 출력은 모두 0으로 유지하고 CONTINUOUS_RAMP_WARMUP으로 다음 주기를 기다린다. 가상 램프 상태만 다음 전진 가능한 단계로 진행한다.
- qv<0 또는 절대 RPM>10이면 계속 STOP_WHEEL_BOUND로 종료한다.
- 각속도 slew 뒤에도 두 바퀴 속도를 함께 비례 축소해 물리적 10RPM 상한을 다시 적용한다. 곡률/속도 상한을 높이지 않는다.
- 후보 v/w, 반올림 RPM, qv/qw, 마지막 축소 비율을 wheel_diagnostic으로 기록한다.
- 차체 여유 검사는 램프 처리보다 먼저 수행하며, 이동이 가능한 정수 RPM이 나온 뒤에는 기존 현재/예측 이동 영역 검사를 계속 수행한다.

운영자만 다시 실행하면 적용된다. 드라이버 재시작은 필요 없다. 실물 검증 전 후보이며 평가 판정은 변경하지 않는다.
