# UDP·ROS 동시 전달 관찰

check_udp_ros_delivery.py는 지정한 상대 IPv4/UDP42017에38바이트표본을20Hz로보낸다. 상대는 같은표본을echo하며, 수신gap·순번·송신자monotonic기준RTT를기록한다. RTT는장치간시계동기화를요구하지않는다. 상대IP/포트/프로토콜/세션을검사한다. 모터·서비스·ROS발행·설정변경은없다.

ROS는기존 /leader/odom,/leader/path와로컬filtered또는follower를BestEffort1로구독한다. 같은프로세스의50ms실행간격도기록한다. 시작20초를제외한요약과원본시각행을종료후저장한다. 전송/수신이모두늦어도관찰자실행간격이늦으면네트워크원인으로확정하지않는다. UDP만정상이라고ROS DDS결함으로즉시확정하지않으며전송경로/QoS/데이터크기차이를함께고려한다.

양쪽120초진단을거의동시에실행한다. 첫비교는정지상태. 한쪽만실행하면echo수신이없으므로그결과로전달성능을판단하지않는다. 기존노드·Wi-Fi절전OFF상태는유지한다. 로스백은켜지않는다. 특정포트가사용중이면bind실패로중단하며다른프로세스를종료하지않는다. 방화벽/라우터/ROS설정은자동변경하지않는다.

메시지형식·오류패킷거부·초기구간제외·ROS만공백·공통공백·UDP미수신·순서뒤바뀜·빈기록의모의테스트8개통과. 실제무선전달은사용자실행결과로확인해야한다.
